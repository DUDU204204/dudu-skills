# Hebrew Captions — כתוביות עברית עם RTL תקין

מנוע כתוביות עברית שנלמד בכאב (2026-07-16) על סרטוני קורס בעברית. מייצר קובץ ASS
(libass) ומחיל אותו עם ffmpeg. **כל הכללים כאן הם חובה** — כל אחד מהם תוקן אחרי באג אמיתי.

## ⚠️ חמשת חוקי הזהב (כל אחד = באג שקרה)

1. **RTL = עטיפת כל קלף ב-RLE(U+202B)...PDF(U+202C).** בלי זה, הפיסוק (נקודה/פסיק/סימן
   שאלה) יוצא **בצד ימין (תחילת השורה) במקום שמאל (סוף)**. אומת מול טקסט עם מספרים,
   פסיקים ונקודות — RLE מסדר הכל. (הערה: reel_studio טען ש"RLE הופך" — **שגוי**; שם עבד
   רק כי הקלפים היו קצרים בלי פיסוק. עם פיסוק — RLE חובה.)
2. **`Spacing=0` חובה בסגנון.** כל ריווח-אותיות חיובי הופך את סדר ה-glyphs של RTL ב-libass.
3. **קלפים קצרים** (עד ~5 מילים / ~32 תווים), מתחלפים — לא סגמנטי-תמלול ארוכים שגולשים
   מהמסך. שורות ארוכות גם מבלבלות את ה-bidi. חלוקת-זמן פרופורציונלית לאורך התו.
4. **בלי צל** (`Shadow=0`). הילת-בורדר רכה `{\bord3\blur6\shad0}` פר-שורה במקום קו שחור
   צפוף (נראה "עמוס"). פונט: **Assistant ExtraBold**, Fontsize ~64, `Alignment=2`
   (תחתית-מרכז), `MarginV~90` (מוגבה מעט).
5. **⚠️ תצוגה מקדימה:** `-ss` *לפני* `-i` מאפס PTS → הכתוביות לא מסתנכרנות בחילוץ פריים
   בודד ולא רואים אותן. **תמיד seek *אחרי* הקלט:** `ffmpeg -i vid -vf ass=x.ass -ss T -frames:v 1 out.png`. ברינדור מלא (מ-0) זה לא בעיה.

## הכלי

[`make_subs.py`](make_subs.py) — מקבל תמלול JSON (segments עם start/end/text) ומייצר ASS
מסונכרן, עם עטיפת RLE, קלפים קצרים, ומילון תיקונים.

```bash
python3 ~/.claude/skills/hebrew-captions/make_subs.py \
  <transcript.json> <cut_start> <cut_end|end> <intro_dur> <out.ass> \
  [max_words=5] [max_chars=32] [fontsize=64] [marginv=90]
```
- `cut_start/cut_end` — אם הסרטון נחתך, בשניות של המקור (מסנן סגמנטים לטווח).
- `intro_dur` — אם יש פתיח לפני התוכן (הכתוביות יוזזו: `edited = source - cut_start + intro_dur`). 0 אם אין.

## מילון תיקוני-תמלול גלובלי

`caption_fixes.json` (ליד make_subs.py, או בתיקיית העבודה) — זוגות `שגוי:נכון` שמוחלים על
**כל** הכתוביות. שגיאת ASR חוזרת = מתקנים פעם אחת, מתוקן בכל הסרטונים. דוגמה מהקורס:
`{"מרפאה ועיסוק": "מרפאה בעיסוק"}`. כשמזהים טעות — מוסיפים למילון (מתקן רטרואקטיבית וקדימה).

## צריבה לסרטון

```bash
ffmpeg -i video.mp4 -vf "ass=subs.ass" -c:v libx264 -crf 18 -preset medium -c:a copy out.mp4
```
כתוביות רק אחרי פתיח: התזמונים ב-ass כבר מוזזים ב-`intro_dur`, אז אין cue לפני הפתיח.

## תמלול עברית איכותי

המודל: **ivrit-ai/whisper-large-v3-turbo** (סקיל `transcribe`) — עברית מצוינת, מחזיר
segments עם חותמות זמן. זה המקור לכתוביות; לא מתמללים מחדש אם ה-JSON קיים.

## מלכודות ffmpeg נוספות (מאותו סשן)

- **HDR→SDR:** סרטוני אייפון 4K הם HLG/10-ביט. קידוד ישיר ל-8-ביט = צבעים מעוותים. חובה
  tonemap: `zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv,format=yuv420p`.
- **לוגו-watermark:** PNG יחיד באוברליי נעלם אחרי פריים ראשון → `-loop 1 -i logo.png` + `overlay=...:shortest=1`. רק אחרי פתיח: `overlay=...:enable='gt(t,10)'`.
- **pkill:** `pkill -f "<name>.mp4"` תופס גם את ה-ffmpeg החדש שכותב לאותו שם → הורג את עצמו. להרוג לפי PID / להריץ דרך סקריפט.

הקשר מלא לסרטוני הקורס: זיכרון `reference_pesia_video_pipeline`.
